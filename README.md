# mpox_phylogeo

xml/ contains files from which the trees that appear in the thesis can be reproduced in BEAST2
log/ contains BEAST2 logfiles for all trees
trees/ contains MCC trees and the Nextstrain tree
scripts/ contains a script adapted from Thompson et. al to jitter node depths (scripts to perform other steps for tree encoding & running the models can be found on their github: (https://github.com/ammonthompson/phylogeo_epi_cnn/tree/main)) and the script for summarizing import and export clusters on the typed MCC tree from BDMM-Prime
